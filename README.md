# Namma Velai - Tamil Public Website

This version is designed as a Tamil-first public job portal:
- New job notification posters
- This-month jobs
- Government jobs section
- Search and category filter
- Poster click opens job details
- Official application link
- WhatsApp application assistance
- Mobile-friendly layout
- Expired jobs are hidden from public listings

IMPORTANT:
1. Keep your existing Supabase project and `jobs` table.
2. Put your existing Supabase Publishable Key into `config.js`.
3. Keep your existing `admin.html`, `admin.js`, and `admin.css` if your current admin panel is working.
4. Replace only the public website files (`index.html`, `styles.css`, `app.js`, `job.html`, `job.js`, `config.js`) in GitHub.
5. Never publish a Supabase service_role/secret key.
